# 量化选股（L1–L7）现状和规矩

写于 2026-11-18。页面 `/quant-selection`，代码在 `backend/app/quant/layered_selection.py`、`market_regime.py`、`layered_selection_api.py`、`skills/quant_selection.py`。这套代码是 2026-11-18 由另一个 AI（Gemini）写的，同一天按下面的规矩改过一次。

## 它做什么

- L1 大盘环境：看站上均线的股票比例、两市成交额分位、沪深 300 和中证 1000 的趋势，分进攻、中性、防守，给出总仓位上限 90%、60%、30%。
- L2–L6 分层打分：行业、基本面、预期差、时机（模型排名占一部分）、事件，按波段、长线、事件三套权重合成总分，给“动手/观察/放弃”。
- 排雷：立案调查、退市风险、财务造假、ST 直接排除；全市场公告每天入库（`stock_event_signals`）。
- 每天收盘后跟在自动选股后面算一遍，存 `stock_selection_daily_snapshot`，历史每天的结论都留着。

## 和操作计划统一的三处（2026-11-18）

页面、数字人和操作计划原来各算各的，会给出两个价、两个股数。现在都用操作计划那一套代码：

1. **挂买价**：只来自买入模型（`order_engine.model_buy_price`，昨收和 ATR 用 `plan_orders` 算，和 `plans/quant_orders.model_buys` 一样）。模型说不挂、当天没有信号或者价低于跌停，都不给买价。原来的统计表买价（没跑赢简单基线）和“昨收减 0.5 倍 ATR”兜底都去掉了。
2. **止损**：只给下限，用 `plan_orders(...).stop`，也就是昨收减 3 倍 ATR（不低于跌停价）。原来是 2 倍 ATR，回测里这么近的止损把年化打成负数。页面上写成“止损不高于”，可以不设。
3. **股数**：`shadow/rules.target_shares` + `plans/quant_sizes.budget_for` × `rank_tilt`，和计划的量化股数同一个公式。计划里的资金只算已有持仓的市值；这里是新开仓，用账户预算代替，验证过的股数规则不开新仓，所以只作参考。已经持有的股票不另算，以操作计划为准。不再看 L1 仓位上限（没验证），用户也不能自己选风险比例。

数字人技能（`skills/quant_selection.py`）改成只查信息：引用分层得分和结论时要说明没有回测；写计划时买价、止损和股数以计划提示里系统算好的为准。

## 还没做的

1. 和自动选股合并：两个菜单合成一个“选股”，分层总分改成自动选股里的一个挑战者，用同一套前瞻评估比成绩；“动手”结论在回测通过前改成中性说法。
2. 页面上的“前瞻净值对比”（`update_shadow_nav_comparison`）按前一天收盘价买入、每天换仓、不扣费，偏乐观；里面叫 `model-rank-30` 的那条也不是自动选股里验证过的那个（没有成交额底线、不是 10 天一换）。要改成次日开盘成交、扣费、和回测同一套规则，改好之前不能用它比优劣。
3. 补回测：先写通过标准，再用 2018 年以前的数据测 L1 仓位上限和分层总分；通过了再测 2019 年以后，只跑一次。需要先装好计算环境，L3、L4、L6 还要补下历史财报和全市场公告。
4. 往后看的对账：每天的结论已经存在快照表里，可以加一个自动对账，“动手”和“放弃”到期后和全市场平均比，攒 2 到 3 个月再看。前提是这期间不改权重、不回头重算旧日期。
