双击 `index.html` 在浏览器打开，可切换三个页面和查看原始尺寸。无需联网或安装依赖。需要转发时，发送完整 ZIP，解压后打开，不要单独转发 HTML。

评审重点：三页分工是否清楚；失败/未到期/不足是否清楚；收益和风险是否同等可见；正式切换和回退责任是否明确。
