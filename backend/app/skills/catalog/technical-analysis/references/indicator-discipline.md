# 技术指标使用纪律

## 均线

均线用于观察趋势和成本变化。均线多头排列需要价格结构和量能确认；短期均线交叉在震荡市容易反复失效。

## MACD

- 零轴位置反映中期方向背景；
- DIF/DEA 交叉反映动量变化；
- 柱体缩短不等于趋势已经反转；
- 背离需要两个可比的价格波段。

## RSI

超买说明上涨动量强，不等于立即下跌；超卖同理。趋势行情中 RSI 可以长时间停留在极端区间。

## 布林带

带宽收缩表示波动压缩，不预测突破方向。价格沿上轨运行可能是强趋势，不应机械理解为超买。

## 量价

| 价格 | 成交量 | 常见解释 |
|---|---|---|
| 上涨 | 放大 | 趋势获得参与度确认 |
| 上涨 | 缩小 | 追价意愿下降，需观察 |
| 下跌 | 放大 | 抛压或分歧扩大 |
| 下跌 | 缩小 | 抛压衰减，也可能是流动性不足 |

所有解释都需要结合位置、换手、事件和市场环境。
