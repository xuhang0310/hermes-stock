# 回测验证协议

## 必查偏差

- 未来数据泄漏；
- 使用当前成分股回测历史造成幸存者偏差；
- 按完整样本选择最优参数；
- 忽略停牌、涨跌停和成交量；
- 使用收盘价产生信号又按同一收盘价成交；
- 忽略分红、复权和公司行动；
- 忽略手续费、滑点和冲击成本。

## 最低输出

| 维度 | 指标 |
|---|---|
| 收益 | 累计、年化、相对基准 |
| 风险 | 波动率、最大回撤、回撤持续期 |
| 风险调整 | Sharpe、Calmar（口径明确） |
| 交易 | 次数、胜率、盈亏比、换手 |
| 稳健性 | 分年度、参数邻域、样本外 |

## 结论

高回测收益不能证明未来有效。结论应聚焦策略在哪些市场状态有效、在哪些状态失效，以及需要怎样的前向验证。
