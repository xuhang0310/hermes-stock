# 资金行为与筹码分析

资金数据的统计口径差异很大。先解释“这组数据统计了什么”，再解释它可能意味着什么。

## 执行流程

1. 确认标的、日期窗口和是否存在停牌、除权或异常换手。
2. 获取资金流、龙虎榜、融资融券或筹码数据。
3. 记录来源、统计口径、单位和数据日期。
4. 将单日数据放入至少 5 至 20 个交易日的背景中。
5. 用价格、成交量和换手率交叉验证。
6. 区分方向性证据、情绪性证据和无法归因的数据。

## 口径纪律

- “主力净流入”通常是按成交单大小分类，不等于某个可识别机构真实买入。
- 龙虎榜只覆盖满足披露条件的交易日和席位，不代表全部资金。
- 融资余额增长可能来自看多，也可能是价格上涨带来的余额变化。
- 筹码分布是模型估算，不是账户级真实持仓。
- 不同平台资金流数值不可直接拼接。

详细口径见 [references/caliber.md](references/caliber.md)。

## 组合判断

至少回答：

- 资金行为是单日异常还是持续趋势？
- 价格是否确认资金方向？
- 融资、龙虎榜和筹码信号是否相互一致？
- 是否存在事件驱动造成的短期失真？
- 如果结论错误，下一步会看到什么信号？

## 回答要讲到

用白话结论做小标题（如“融资盘在撤，但只是这两天”），不照抄下面的条目：

- 看的是哪段时间的什么数据，这些数据统计的是什么（如“主力净流入”其实是按单笔成交大小分的）；
- 资金是持续流入/流出还是单日异常；
- 融资、龙虎榜、筹码说的是不是同一件事；
- 价格和成交量有没有跟着确认；
- 另一种可能的解释，以及看到什么说明判断错了。
