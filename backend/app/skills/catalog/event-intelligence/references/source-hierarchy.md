# 事件来源核验

## 去重

将标题不同但引用同一公告、同一采访或同一通讯社稿件的页面视为一个来源。交叉核验要求来源在事实采集链上相互独立。

## 日期

同时记录：

- `published_at`：页面发布时间；
- `event_date`：事件实际发生时间；
- `data_as_of`：研究采用材料的截止时间。

旧新闻重新传播时，不能按新事件处理。

## 公告解读

1. 阅读公告标题和正文，而不是只看媒体摘要。
2. 识别是否为计划、签约、框架协议、正式订单或已确认收入。
3. 检查金额占最近一期收入或净资产比例。
4. 检查生效条件、履约周期、交易对手和不确定性提示。
5. 对问询函、处罚和风险提示保留原始措辞。

## 传闻

传闻可以解释短期情绪，但不得写成公司事实。输出时标记“未由公司或监管披露确认”，并给出验证路径。
