# 财务红旗与口径检查

## 目录

1. 盈利质量
2. 资产质量
3. 现金与债务
4. 口径一致性

## 盈利质量

- 应收账款增速连续高于收入增速；
- 存货增长快于收入且周转持续下降；
- 经营现金流长期显著低于净利润；
- 非经常性损益占利润比例过高；
- 毛利率与同行趋势明显背离但没有业务解释；
- 研发资本化、利息资本化或减值政策显著改变利润。

这些是调查信号，不是自动判定造假的证据。

## 资产质量

- 商誉、无形资产或在建工程占比异常；
- 大额关联方应收和其他应收款；
- 货币资金很高但同时高息借款很高；
- 受限资金、质押、担保或表外承诺披露不足；
- 长期股权投资价值与被投资公司经营状况不匹配。

## 现金与债务

```text
盈利现金比 = 经营活动现金流 / 归母净利润
应计比例 = (净利润 - 经营活动现金流) / 平均总资产
短债覆盖 = 可自由支配现金 / 一年内到期有息负债
```

比率需要结合行业、季节性和报告期判断，不能机械套用。

## 口径一致性

- 单季与年初至今累计不可直接同比；
- 归母净利润与公司整体净利润不可混用；
- PE 的利润口径必须与市值口径一致；
- 预测值必须标记 `E`，实际值标记 `A`；
- 同一报告内金额单位保持一致；
- 遇到来源偏差时优先法定披露，并说明差异。
