# 文件持续修改生命周期

## 定位

优先级：

1. 用户本轮明确上传或提到的文件；
2. 当前会话活动产物；
3. 最近生成且类型匹配的产物；
4. 工作区搜索结果。

多个候选具有相近可信度时停止写入并确认。

## 修改

建立变更计划：

- 保留什么；
- 修改什么；
- 新增什么；
- 如何验证。

修改范围越小，越容易保持原文件质量和用户意图。

## 验证

- 文本：关键段落、结构和编码；
- 代码：语法、测试和差异；
- Word/PDF：渲染页数、字体和溢出；
- PPT：缩略图、页面尺寸、元素越界；
- Excel：公式错误、数据类型和关键单元格。

## 回滚

每次写入生成新版本。验证失败时保留失败记录，但活动版本应指向最近有效版本或明确标记不可用。
