# 组合风险指标

## 集中度

```text
单票权重 = 标的市值 / 组合总市值
HHI = Σ(单票权重²)
```

权重需要包含现金并明确总市值口径。

## 相关性

相关性依赖时间窗口和市场状态。平静期低相关的资产在危机中可能同步下跌。至少说明收益频率、窗口长度和缺失数据处理。

## 流动性

可关注持仓市值相对日均成交额、涨跌停制度、停牌和大股东减持。不能仅用市值判断退出能力。

## 压力情景

- 市场指数快速回撤；
- 所属行业估值压缩；
- 关键商品或汇率不利变化；
- 最大持仓出现基本面事件；
- 多个止损阈值同时触发。

压力测试用于暴露脆弱点，不是精确预测损失。
