# 研究纪律与反证

这个技能不替代研究流程，而是在研究开始和结束时校正方向。专业研究最常见的问题不是不会计算，而是只寻找自己愿意相信的材料。

## 开始前检查

| 偏差 | 常见表现 | 修正动作 |
|---|---|---|
| 龙头偏差 | 只研究知名大市值公司 | 主动检查中小市值、供应商和替代方案 |
| 叙事偏差 | 把“AI、机器人、低空经济”等标签当成收入 | 回到产品、客户、收入占比和单位经济性 |
| 确认偏差 | 形成观点后只搜支持材料 | 为每个核心多头观点主动寻找反方证据 |
| 新近偏差 | 把最新新闻当成最重要信息 | 区分短期事件与长期基本面变量 |
| 精确幻觉 | 对主观概率和远期预测给出精确小数 | 使用情景、触发条件和区间，不伪造精度 |
| 幸存者偏差 | 只看成功公司或有效策略 | 检查失败样本、退市样本和失效区间 |
| 口径偏差 | 混用母公司/合并、单季/累计、GAAP/调整后 | 在比较前统一口径 |

## 研究中

1. 把事实、推断和假设分开记录。
2. 重大数字记录来源、日期、单位和统计口径。
3. 结论依赖单一来源时标记“单源，待交叉核验”。
4. 搜索不到证据不代表反面成立。
5. 数据缺失时缩小结论，不用模型常识填补公司特定事实。

## 结论前反证

- 哪一条证据最可能推翻当前结论？
- 是否存在同样数据但不同解释？
- 是否把相关性误写成因果关系？
- 是否遗漏了负面公告、现金流恶化或估值约束？
- 是否因为用户持仓而无意识地给出安慰性结论？
- 如果观点错误，最早会出现什么可观察信号？

## 输出要求

正文不需要展示完整偏差检查表，但应体现：

- 至少一项反方证据或反方解释；
- 结论的适用条件和失效条件；
- 关键数据缺口；
- 与证据强度匹配的置信度。
