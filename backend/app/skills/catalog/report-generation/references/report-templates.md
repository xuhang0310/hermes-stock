# 报告模板

## 公司研究备忘录

```markdown
# [公司]研究备忘录
> 代码 / 数据截止日 / 研究状态

## 执行摘要
## 核心观点与证据
## 业务和行业
## 财务质量与估值
## 行情、事件和资金
## 反方论证
## 催化、风险和失效条件
## 数据缺口
## 来源
```

## 事件点评

```markdown
# [事件]点评
## 发生了什么
## 已确认事实与时间线
## 影响传导
## 市场预期与价格反应
## 反方解释
## 后续验证点
```

## 回测报告

```markdown
# [策略]回测报告
## 策略定义和假设
## 数据、基准和成本
## 核心绩效
## 分阶段表现
## 回撤和风险
## 稳健性与失效区间
## 局限和下一实验
```
