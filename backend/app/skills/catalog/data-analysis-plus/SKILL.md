# 数据分析方法论

将分散的数据转化为精准洞察，实现"数据→洞察→行动"闭环。

## 四大核心能力

### 1. 多源数据采集与整合

- 整合 TuShare 行情、财务报表、公告、新闻、资金流等多源数据
- 联网检索补充行业报告、政策文件、专家观点
- 数据缺失时明确标注口径和来源，不伪造数据

### 2. 舆情与情绪分析

- 监测个股/板块相关新闻情绪倾向（正面/负面/中性）
- 识别舆情爆发源头与传播路径
- 负面舆情集中时触发风险预警，在结论中明确标注

### 3. 财务指标多维度拆解

- 核心指标体系：ROE/ROA/净利率/毛利率/资产负债率/现金流
- 按时间维度（季度趋势）、同行维度（行业对比）拆解
- 识别指标间矛盾信号（如净利润增长但现金流恶化）

### 4. 结构化报告输出

- 核心数据 → 关键洞察 → 行动建议，三层结构
- 数据可视化建议：折线图（趋势）、柱状图（对比）、饼图（占比）
- 所有结论标注数据来源和时间点

## 分析原则

1. **数据先行**：先收集数据，再形成观点；不要先有结论再找证据
2. **口径一致**：比较数据前统一统计口径（单季/累计/TTM，合并/母公司）
3. **交叉核验**：核心结论至少两个独立来源支撑
4. **矛盾标注**：不同来源数据冲突时，明确标注差异，不静默取舍
5. **把握说清**：数据不充分时缩小结论范围，用“比较确定/还要看……”说明把握，不写置信度标签
6. **时效意识**：注明数据时间点，区分实时数据与历史快照

## 输出规范

回答先给结论，再用白话讲到（不照抄这些标签做标题）：

- 关键数字是多少、来自哪里、哪天的；
- 和自己的历史、同行或行业平均比怎么样；
- 有哪些异常、互相矛盾的数据或负面消息；
- 根据数据可以怎么做（写成条件式，末尾一句话说明不构成投资建议）

## 与其他技能的协同

- 与 `financial-statement-analysis` 配合：深度财务报表分析
- 与 `technical-analysis` 配合：技术面与基本面交叉验证
- 与 `research-discipline` 配合：避免确认偏差，主动寻找反方证据
- 与 `report-generation` 配合：结构化报告最终交付
