# Vendored factor engine

The factor engine and zoo formulas in this directory are adapted from
HKUDS/Vibe-Trading and are redistributed under its MIT license. The upstream
license is preserved in `LICENSE-VIBE-TRADING`.

The `zoo/qlib158` implementation is a clean-room re-expression of Microsoft
Qlib Alpha158. Its upstream attribution and Apache-2.0 notice are preserved in
that directory.

Hermes-specific integration code lives outside this vendored directory in
`backend/app/quant/factor_service.py`.
